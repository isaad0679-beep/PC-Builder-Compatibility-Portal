PC Builder & Compatibility Checker Portal

 Project Description
The PC Builder & Compatibility Checker Portal is a Python-based project. It helps users select PC components, check compatibility, calculate the total PC cost, and generate a build report.

 Features
- User login system
- Display all available PC components
- Search components by name
- Add new components
- CPU and motherboard compatibility checking
- RAM and motherboard compatibility checking
- PC build budget calculator
- Generate and save PC build reports

 Technologies Used
- Python
- Jupyter Notebook
- JSON
- File Handling

 Project Structure
```text
pc_builder/
│
├── pc_builder.ipynb
├── README.md
└── pc_builder_data/
    ├── pc_components.json
    └── pc_build_report.txt
```

 How to Run
1. Open `pc_builder.ipynb` in Jupyter Notebook.
2. Run the notebook cells in order.
3. Enter the login credentials when requested.
4. Use the main menu to access the portal features.

 Data Storage
PC component information is stored in a JSON file. Generated PC build reports are saved as text files.

 Project Purpose
This project demonstrates Python functions, loops, lists, conditional statements, file handling, JSON storage, and exception handling.
